## How to actually use EGM

EGM (Elephant Goldfish Model) is Google's experimental review plugin. It is **not installed** in this OpenCode instance (no `opencode.json`, no `egm` agent registered). The `elephant-goldfish-model/` directory in this repo is the plugin source.

### Installation (per `elephant-goldfish-model/docs/opencode.md`)
1. Requires Python 3.10+ and OpenCode CLI **1.18.29** exactly.
2. Install: `python3 adapters/opencode/install.py /absolute/egm-opencode-candidate`
3. Inspect generated `opencode.json` and `installation.json`.
4. Launch: `OPENCODE_CONFIG=/absolute/egm-opencode-candidate/opencode.json opencode --agent egm`
5. Select the `egm` primary agent before using native skills.

### EGM workflow (from `skills/egm-review/SKILL.md`)
- Requires a **TargetFile** (design document) as input.
- Curated pipeline presets: Interactive, Consolidated, Feature spec only, Implementation plan only.
- 5 stages: Initial Zoom Out (5) → Comprehension (6) → Critic (7: design/structural/style) → Intermediate Zoom Out (8) → Implementation Readiness (9: implementation-readiness/codebase-details/style).
- Each stage spawns subagents defined in `agents/<name>.md` (e.g. `egm-zoom-out`, `egm-design`, `egm-structural`, `egm-style`, `egm-comprehension`, `egm-implementation-readiness`, `egm-codebase-details`).
- Artifact-first delivery: findings written to files (`zoom_out_report.md`, `comprehension_report.md`, `critic_report.md`, `intermediate_zoom_out_report.md`, `implementation_readiness_report.md`, `consolidated_review_report.md`), not chat.
- Checkpoint gates between stages (interactive mode).

### Since EGM is not installed here
I emulated the EGM reviewers using `general` subagents with the persona prompts from `elephant-goldfish-model/agents/*.md`. The findings above are the result. To use the real EGM, install it per the docs and run with the `egm` agent.
